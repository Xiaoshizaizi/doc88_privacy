隐私权政策Privacy Policy — Doc88 Downloader Chrome Extension

最后更新 / Last Updated：2026-09-25

一、概述 / Overview

本扩展程序（"道客巴巴下载器"）尊重并保护用户隐私。本政策说明该扩展如何（以及如何不）处理用户数据。简单来说：本扩展不收集、不上传、不共享任何用户数据。

This Chrome extension ("Doc88 Downloader") respects your privacy. In short: it does not collect, transmit, or share any user data.

二、不收集个人数据 / No Personal Data Collected

  • 不收集姓名、邮箱、电话、地址等任何可识别个人身份的信息；
  • 不收集浏览历史、搜索记录或页面内容；
  • 不使用任何统计、埋点或广告 SDK。

We do not collect any personally identifiable information, browsing history, or page content. No analytics, tracking, or advertising SDKs are used.

三、本地存储 / Local Storage

扩展使用浏览器本地存储（chrome.storage.local）仅保存一项授权状态标志（是否已授权及授权日期），用于避免用户重复输入授权码。该信息仅保存在用户本机，不会同步、不会上传，卸载扩展后即被彻底清除。

The extension uses chrome.storage.local to store only a local authorization flag (a boolean and a date) so the user does not need to re-enter an authorization code. It stays on the user's device only and is removed when the extension is uninstalled.

四、生成的文件 / Generated Files

用户使用"导出 PDF"功能生成的 PDF 文件仅保存到用户本机的下载目录，由用户自行保管。扩展程序不读取、不上传、不备份这些文件。

PDF files generated by the extension are saved locally to the user's download folder. The extension never reads, uploads, or backs up these files.

五、网络访问 / Network Access

本扩展不设任何服务器，不会将任何数据发送至开发者或任何第三方服务器。扩展请求的网站访问权限仅限于三个文档预览网站（doc88.com、wenku.baidu.com、book118.com），用于在页面上提供"导出 PDF"按钮。

The extension has no server and sends no data to the developer or any third party. Its host access is limited to three document-preview sites (doc88.com, wenku.baidu.com, book118.com) solely to provide the "Export PDF" button on those pages.

六、儿童隐私 / Children's Privacy

本扩展不面向 13 岁以下儿童，也不会有意收集儿童的任何个人信息。

The extension is not directed to children under 13 and does not knowingly collect any personal information from children.

七、政策更新 / Changes to This Policy

本政策如有更新，将在本页面发布并更新"最后更新"日期。

Any changes to this policy will be posted on this page with an updated date.
